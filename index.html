Building SAMOFFER: Proposal & Invoice Automation

A lightweight FastAPI tool I built to help local businesses and tradesmen turn a service into a polished, shareable PDF proposal in seconds.

SAMOFFER started as a way to cut out the manual, repetitive part of writing proposals and invoices for small workshops and tradesmen — typing the same layout over and over just to send a quote. The panel runs locally and is reachable from any device on the same network, so a proposal can be put together from a phone just as easily as a desktop.

Under the hood it's a Python 3.10+ / FastAPI backend served with Uvicorn, rendering Jinja2/HTML templates and generating print-ready PDFs with XHTML2PDF and ReportLab. Customer and product data lives in a local SQLite database, keeping the whole thing dependency-light and easy to run.

  • Generates a structured proposal in seconds
  • Instant, print-ready PDF output
  • Customer & product records stored locally
  • Built for sharing straight to WhatsApp

Samorganizer: Taming a Messy Downloads Folder

A small Python script born out of a chaotic Downloads folder — sorts files into Images, Documents, Videos, Music and more with a single double-click.

Samorganizer is a script I wrote after getting tired of digging through a Downloads folder full of unsorted files. It scans a target folder and moves each file into a subfolder based on its extension — images, PDFs and documents, videos, audio, archives, executables, and a catch-all "Others" folder for anything unrecognized.

It's pure Python 3 with no external dependencies, so it runs anywhere Python does. A bundled .bat file organizes the Downloads folder with one double-click on Windows, using the current user's profile path so it works without editing anything.

  • Sorts by extension into clearly named subfolders
  • No third-party libraries required
  • One-click Windows shortcut included
  • Skips files already inside a matching subfolder on future runs
